# Practice Call Scripts

18 prospect-side scripts for live testing DentaVoice Coach.

## How to use
1. Start the app (`npm run dev` on port 3001)
2. Open the app, fill in the practice name/context, hit Start
3. Read the **prospect lines** out loud into your mic (use a different voice/tone)
4. Read the **coaching hints** the app gives you as "Seb" 
5. Continue the conversation following the prospect script

## Tips
- Wait for the app to give you a hint before reading the next prospect line
- Speak clearly — Deepgram needs to hear both sides
- Use headphones! (AEC is disabled)
- The prospect lines have [PAUSE] markers — wait for the coach before continuing
